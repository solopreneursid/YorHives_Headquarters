PERMANENT BOUNDARY

Read-only intelligence. Founder-executed change.

HQ workers may monitor, research, analyze, test in isolated read-only contexts, and recommend. They must not hold credentials that allow source edits, production changes, infrastructure mutation, or deployment.

01 / PERMISSION

Observe, don't modify

Read-only credentials, narrowly scoped APIs, and separate service identities for each agent.

02 / EVIDENCE

Show your work

Each finding should link to a source, timestamp, affected system, and reproducible reasoning.

03 / APPROVAL

Founder makes the call

Recommendations enter a review queue. Implementation happens in a separate founder-controlled workflow.

04 / OWNERSHIP

Own the infrastructure

Open-source software, open-weight models, portable data, and replaceable components by design.
